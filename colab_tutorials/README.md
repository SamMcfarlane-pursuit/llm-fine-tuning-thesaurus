# LLM Fine-Tuning Tutorials for Thesaurus AI

This directory contains Google Colab tutorials for fine-tuning language models for the Thesaurus AI project.

## Available Tutorials

1. **Data Preparation Tutorial**
   - `Data_Preparation_Tutorial.ipynb`
   - Learn how to collect, clean, and format data for LLM fine-tuning
   - Covers data augmentation, quality checks, and preparing for different model sizes

2. **Tuning Approaches Comparison**
   - `Tuning_Approaches_Comparison.ipynb`
   - Compare full fine-tuning, LoRA, and QLoRA approaches
   - Understand memory requirements, training time, and performance differences

3. **LoRA Fine-Tuning Tutorial**
   - `LoRA_Fine_Tuning_Tutorial.ipynb`
   - Step-by-step guide to fine-tuning with LoRA
   - Includes code for training, evaluation, and inference

4. **QLoRA Fine-Tuning Tutorial**
   - `QLoRA_Fine_Tuning_Tutorial.ipynb`
   - Comprehensive tutorial on QLoRA fine-tuning
   - Learn how to use 4-bit quantization for efficient training

5. **Pipeline Inference Tutorial**
   - `Pipeline_Inference_Tutorial.ipynb`
   - Guide to using Hugging Face pipelines for inference
   - Create a custom thesaurus pipeline combining WordNet and LLMs

## How to Use These Tutorials

1. Click on any `.ipynb` file to view it on GitHub
2. Click the "Open in Colab" button at the top of the notebook
3. Make a copy of the notebook to your Google Drive to save your work
4. Follow the step-by-step instructions in each notebook
