Using pipeline() for Quick Inference

Key Concepts: pipeline()

The pipeline() function from the Transformers library is the easiest and fastest way to use pre-trained models for inference. It abstracts away the complexity of loading models, preprocessing inputs, and postprocessing outputs, allowing you to focus on your application.

Core Functionality

At its core, the pipeline() function is a high-level abstraction that:

  • Loads the appropriate model and tokenizer for the specified task
  • Preprocesses the input data (tokenization, padding, etc.)
  • Runs inference with the model
  • Postprocesses the output into a human-readable format

Key Benefits of pipeline()
Simplicity

Efficiency

Handles batching and device placement automatically for optimal performance.

Consistency

Provides a unified interface across different models and tasks.

Advanced Concepts
Device Management

The pipeline() function can automatically manage device placement:

from transformers import pipeline

# Run on CPU
pipe = pipeline("text-generation")

# Run on specific GPU
pipe = pipeline("text-generation", device=0)

# Run on multiple GPUs
pipe = pipeline(
    "text-generation",
    device_map="auto"
)
Batching for Performance

Process multiple inputs efficiently with batching:

from transformers import pipeline

pipe = pipeline("sentiment-analysis")

# Process a batch of inputs
results = pipe([
    "I love this product!",
    "This is terrible.",
    "Quite average experience."
])

# With explicit batch size
pipe = pipeline(
    "text-classification",
    batch_size=32
)

Using pipeline() with Your Fine-tuned Models

The pipeline() function works seamlessly with your fine-tuned models, making it easy to deploy them for inference.

Standard Fine-tuned Models
Python
from transformers import pipeline

# Load a fine-tuned model with pipeline
my_pipeline = pipeline(
    "text-generation",
    model="./my-finetuned-model",
    tokenizer="./my-finetuned-model"
)

# Use the pipeline
result = my_pipeline(
    "The quick brown fox",
    max_length=30,
    num_return_sequences=1
)

print(result[0]['generated_text'])
When to use this approach:
  • For models fine-tuned using standard methods
  • When the entire model was updated during fine-tuning
  • For models saved with model.save_pretrained()
PEFT Fine-tuned Models (LoRA)
Python
from peft import PeftModel, PeftConfig
from transformers import AutoModelForCausalLM, AutoTokenizer, pipeline

# Load the PEFT configuration
config = PeftConfig.from_pretrained(
    "./thesaurus-model-lora"
)

# Load the base model
base_model = AutoModelForCausalLM.from_pretrained(
    config.base_model_name_or_path
)

# Apply the LoRA adapter
model = PeftModel.from_pretrained(
    base_model,
    "./thesaurus-model-lora"
)

# Load the tokenizer
tokenizer = AutoTokenizer.from_pretrained(
    "./thesaurus-model-lora"
)

# Create a pipeline with the fine-tuned model
my_pipeline = pipeline(
    "text-generation",
    model=model,
    tokenizer=tokenizer
)
When to use this approach:
  • For models fine-tuned with PEFT methods (LoRA, QLoRA, etc.)
  • When only adapter weights were trained
  • When you need to merge adapters with the base model
Pro Tips for Using pipeline() with Fine-tuned Models
  • Always specify the correct task type (e.g., "text-generation", "text-classification")
  • For PEFT models, you can merge the adapter with the base model using model.merge_and_unload() for faster inference
  • Use device_map="auto" to automatically place the model on available devices
  • For large models, consider using quantization to reduce memory usage
  • Cache your pipeline for repeated use to avoid reloading the model

Thesaurus Application
Use Case

Build a thesaurus application that generates synonyms for any word using a fine-tuned language model.

Python
from transformers import pipeline

# Load your fine-tuned thesaurus model
thesaurus = pipeline(
    "text-generation",
    model="./thesaurus-model-lora",
    tokenizer="./thesaurus-model-lora"
)

def get_synonyms(word):
    prompt = f"Find synonyms for: {word}\n\nSynonyms:"
    result = thesaurus(
        prompt,
        max_length=50,
        num_return_sequences=1,
        temperature=0.7
    )
    return result[0]['generated_text']

# Example usage
print(get_synonyms("happy"))

Multi-task Text Analysis
Use Case

Create a comprehensive text analysis tool that combines sentiment analysis, named entity recognition, and summarization in one function.

Python
from transformers import pipeline

# Create multiple pipelines
sentiment = pipeline("sentiment-analysis")
ner = pipeline("ner", aggregation_strategy="simple")
summarizer = pipeline("summarization")

def analyze_text(text):
    # Get sentiment
    sentiment_result = sentiment(text)[0]

    # Extract entities
    entities = ner(text)

    # Summarize text if it's long enough
    summary = ""
    if len(text.split()) > 30:
        summary = summarizer(
            text,
            max_length=30,
            min_length=10
        )[0]['summary_text']

    return {
        "sentiment": sentiment_result,
        "entities": entities,
        "summary": summary
    }

# Example usage
result = analyze_text("Hugging Face is a company based
in New York and Paris. They develop amazing NLP tools.")

Building a Web API with pipeline()
Use Case

Create a simple Flask API that serves predictions from multiple pipeline models.

Python
from flask import Flask, request, jsonify
from transformers import pipeline
import torch

app = Flask(__name__)

# Initialize pipelines (load once at startup)
device = 0 if torch.cuda.is_available() else -1

# Cache pipelines as global variables
text_generator = pipeline("text-generation", device=device)
sentiment_analyzer = pipeline("sentiment-analysis", device=device)
summarizer = pipeline("summarization", device=device)

@app.route('/generate', methods=['POST'])
def generate_text():
    data = request.json
    prompt = data.get('prompt', '')
    max_length = data.get('max_length', 50)

    if not prompt:
        return jsonify({'error': 'No prompt provided'}), 400

    result = text_generator(prompt, max_length=max_length)
    return jsonify({'generated_text': result[0]['generated_text']})

@app.route('/sentiment', methods=['POST'])
def analyze_sentiment():
    data = request.json
    text = data.get('text', '')

    if not text:
        return jsonify({'error': 'No text provided'}), 400

    result = sentiment_analyzer(text)
    return jsonify(result[0])

@app.route('/summarize', methods=['POST'])
def summarize_text():
    data = request.json
    text = data.get('text', '')
    max_length = data.get('max_length', 100)
    min_length = data.get('min_length', 30)

    if not text:
        return jsonify({'error': 'No text provided'}), 400

    result = summarizer(text, max_length=max_length, min_length=min_length)
    return jsonify({'summary': result[0]['summary_text']})

if __name__ == '__main__':
    app.run(debug=True)
Key Benefits:
Efficiency

Pipelines are loaded once at startup and reused for all requests, improving response times.

Simplicity

Clean API endpoints that handle preprocessing and postprocessing automatically.

Scalability

Easy to add new endpoints for different models or tasks as needed.
