Data Preparation for LLM Fine-Tuning

A comprehensive guide to preparing high-quality datasets for effective LLM fine-tuning

Introduction

Proper data preparation is crucial for successful LLM fine-tuning. The quality, format, and structure of your training data directly impact the performance of your fine-tuned model.

Why Data Preparation Matters:
  • High-quality data leads to better model performance
  • Properly formatted data prevents training errors
  • Well-structured data helps the model learn the desired patterns
  • Clean data reduces the risk of biases and hallucinations

Data Collection

The first step in data preparation is collecting relevant, high-quality data for your specific use case.

Common Data Sources
  • Public Datasets: Hugging Face Datasets, Kaggle, etc.
  • Web Scraping: Collecting data from websites
  • APIs: Accessing data through public APIs
  • Existing Corpora: Books, articles, documentation
  • Synthetic Data: Generated using existing models
Data Quality Considerations
  • Relevance: Data should be relevant to your task
  • Diversity: Cover a wide range of examples
  • Balance: Avoid overrepresentation of certain categories
  • Accuracy: Data should be factually correct
  • Recency: Data should be up-to-date if needed

Example: Loading a Dataset from Hugging Face

from datasets import load_dataset

# Load a public dataset
dataset = load_dataset("tatsu-lab/alpaca")

# Display information about the dataset
print(dataset)
print(f"Number of examples: {len(dataset['train'])}")
print(f"Example data point: {dataset['train'][0]}")

Data Cleaning

Raw data often contains noise, errors, and inconsistencies that need to be addressed before fine-tuning.

1

Remove Duplicates

Duplicate examples can lead to overfitting and bias the model toward repeated content.

import pandas as pd

# Convert dataset to pandas DataFrame for easier manipulation
df = pd.DataFrame(dataset['train'])

# Check for duplicates
print(f"Duplicates found: {df.duplicated().sum()}")

# Remove duplicates
df_cleaned = df.drop_duplicates()
print(f"Dataset size after removing duplicates: {len(df_cleaned)}")
2

Handle Missing Values

Missing values can cause issues during training and should be handled appropriately.

# Check for missing values
print(df.isnull().sum())

# Option 1: Remove rows with missing values
df_cleaned = df_cleaned.dropna()

# Option 2: Fill missing values (for certain columns)
df_cleaned['column_name'] = df_cleaned['column_name'].fillna('default_value')
3

Clean Text Data

Text data often requires specific cleaning steps to ensure consistency.

import re

def clean_text(text):
    if not isinstance(text, str):
        return ""
    
    # Remove HTML tags
    text = re.sub(r'<.*?>', '', text)
    
    # Remove extra whitespace
    text = re.sub(r'\s+', ' ', text).strip()
    
    # Remove URLs
    text = re.sub(r'https?://\S+|www\.\S+', '', text)
    
    # Other cleaning steps as needed
    
    return text

# Apply cleaning function to text columns
df_cleaned['text_column'] = df_cleaned['text_column'].apply(clean_text)
4

Filter Out Low-Quality Examples

Remove examples that are too short, too long, or contain inappropriate content.

# Filter out examples that are too short
min_length = 10
df_cleaned = df_cleaned[df_cleaned['text_column'].str.len() >= min_length]

# Filter out examples that are too long
max_length = 1024
df_cleaned = df_cleaned[df_cleaned['text_column'].str.len() <= max_length]

# Filter out examples containing specific patterns (e.g., inappropriate content)
df_cleaned = df_cleaned[~df_cleaned['text_column'].str.contains('inappropriate_pattern')]
