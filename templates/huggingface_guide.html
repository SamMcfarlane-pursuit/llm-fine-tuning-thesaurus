Hugging Face Integration Guide

Learn how to leverage the Hugging Face ecosystem for LLM fine-tuning and deployment

Introduction to Hugging Face

Hugging Face is the leading platform for machine learning collaboration, offering tools, libraries, and infrastructure for building, training, and deploying models. For LLM fine-tuning, Hugging Face provides several key components:

  • 🤗 Transformers: A library providing thousands of pre-trained models for NLP, computer vision, and more.
  • 🤗 Datasets: A library for easily accessing and sharing datasets.
  • 🤗 PEFT: Parameter-Efficient Fine-Tuning methods including LoRA and QLoRA.
  • 🤗 Accelerate: Tools for distributed training across multiple GPUs or TPUs.
  • 🤗 Hub: A platform for sharing models, datasets, and spaces (interactive demos).

Essential Hugging Face Libraries

🤗 Transformers

The Transformers library provides APIs and tools to easily download and train state-of-the-art pre-trained models.

Key Features:
  • Access to thousands of pre-trained models
  • Support for PyTorch, TensorFlow, and JAX
  • Easy model fine-tuning with the Trainer API
  • Built-in pipeline abstraction for inference
  • Model conversion and quantization utilities
# Basic usage example
from transformers import AutoModelForCausalLM, AutoTokenizer

# Load model and tokenizer
model = AutoModelForCausalLM.from_pretrained("distilgpt2")
tokenizer = AutoTokenizer.from_pretrained("distilgpt2")

# Generate text
inputs = tokenizer("Hello, I'm a language model", return_tensors="pt")
outputs = model.generate(**inputs, max_length=50)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))

🤗 PEFT

Parameter-Efficient Fine-Tuning (PEFT) methods enable fine-tuning large models with limited computational resources.

Supported Methods:
  • LoRA: Low-Rank Adaptation of large language models
  • QLoRA: Quantized Low-Rank Adaptation
  • Prefix Tuning: Optimizing continuous prompts
  • P-Tuning: Prompt tuning with trainable continuous vectors
  • Prompt Tuning: Learning soft prompts for LLMs
# LoRA example
from transformers import AutoModelForCausalLM
from peft import LoraConfig, get_peft_model

# Load base model
model = AutoModelForCausalLM.from_pretrained("distilgpt2")

# Define LoRA configuration
lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

# Apply LoRA
peft_model = get_peft_model(model, lora_config)

🤗 Datasets

The Datasets library provides a simple API for accessing and sharing datasets for machine learning.

Key Features:
  • Access to thousands of public datasets
  • Efficient data loading and processing
  • Built-in data preprocessing functions
  • Memory-efficient dataset handling
  • Easy dataset sharing on the Hub
# Loading and processing a dataset
from datasets import load_dataset

# Load a dataset from the Hub
dataset = load_dataset("imdb")

# Apply preprocessing
def tokenize_function(examples):
    return tokenizer(examples["text"], padding="max_length", truncation=True)

tokenized_dataset = dataset.map(tokenize_function, batched=True)

🤗 Accelerate

Accelerate simplifies the process of training models on multiple GPUs, TPUs, or mixed precision without changing your code.

Key Features:
  • Distributed training across multiple GPUs
  • Mixed precision training
  • Gradient accumulation
  • DeepSpeed and FSDP integration
  • Easy configuration via CLI or config files
# Distributed training with Accelerate
from accelerate import Accelerator

# Initialize accelerator
accelerator = Accelerator()

# Prepare model, optimizer, and dataloaders
model, optimizer, train_dataloader = accelerator.prepare(
    model, optimizer, train_dataloader
)

# Training loop
for epoch in range(num_epochs):
    for batch in train_dataloader:
        outputs = model(**batch)
        loss = outputs.loss
        accelerator.backward(loss)
        optimizer.step()
        optimizer.zero_grad()

Hugging Face Hub Integration

Authentication and Setup

To interact with the Hugging Face Hub, you'll need to authenticate using an access token:

Getting Your Token
  1. Create an account at huggingface.co
  2. Go to your profile settings
  3. Navigate to the "Access Tokens" section
  4. Create a new token with appropriate permissions
# Authenticate with the Hub
from huggingface_hub import login

# Method 1: Interactive login
login()

# Method 2: Login with token
login(token="your_token_here")

# Method 3: Store token in ~/.huggingface/token
# Run this once on your machine
login(token="your_token_here", add_to_git_credential=True)

Sharing Models on the Hub

After fine-tuning a model, you can easily share it on the Hugging Face Hub:

# Push a model to the Hub
from transformers import AutoModelForCausalLM, AutoTokenizer

# Load your fine-tuned model and tokenizer
model = AutoModelForCausalLM.from_pretrained("./thesaurus_model_final")
tokenizer = AutoTokenizer.from_pretrained("./thesaurus_model_final")

# Push to the Hub
model.push_to_hub("your-username/thesaurus-model")
tokenizer.push_to_hub("your-username/thesaurus-model")

# For PEFT models
from peft import PeftModel, PeftConfig

# Load the PEFT model
config = PeftConfig.from_pretrained("./thesaurus_model_lora")
model = AutoModelForCausalLM.from_pretrained(config.base_model_name_or_path)
model = PeftModel.from_pretrained(model, "./thesaurus_model_lora")

# Push to the Hub
model.push_to_hub("your-username/thesaurus-model-lora")

Creating Model Cards

A good model card helps others understand your model's capabilities, limitations, and intended use:

Model Card Template
# Thesaurus Fine-Tuned Model

## Model description

This model is a fine-tuned version of `distilgpt2` on a thesaurus dataset. It can generate synonyms, antonyms, and related terms for given words.

## Intended uses & limitations

The model is intended for educational purposes and to assist with vocabulary expansion. It should not be used for critical applications without human review.

## Training data

The model was fine-tuned on a custom thesaurus dataset containing 200 examples of word relationships.

## Training procedure

### Training hyperparameters

- Learning rate: 2e-4
- Batch size: 4
- Optimizer: AdamW
- LR scheduler: Cosine
- Epochs: 3

### Framework versions

- Transformers 4.30.0
- PyTorch 2.0.1
- Datasets 2.12.0
- PEFT 0.4.0
Programmatic Model Card Creation
from huggingface_hub import ModelCard, ModelCardData

# Create model card data
card_data = ModelCardData(
    language="en",
    license="mit",
    library_name="transformers",
    tags=["thesaurus", "nlp", "language", "qlora"],
    datasets=["custom_thesaurus_dataset"],
    metrics=["accuracy", "perplexity"]
)

# Create model card
card = ModelCard.from_template(
    card_data,
    model_id="your-username/thesaurus-model",
    model_description="A fine-tuned language model for thesaurus applications",
    intended_use="Educational purposes and vocabulary assistance",
    limitations="Limited vocabulary coverage",
    training_data="Custom thesaurus dataset with 200 examples",
    training_procedure="Fine-tuned with QLoRA for 3 epochs",
    evaluation_results="Achieved 85% accuracy on test set"
)

# Save and push model card
card.save("README.md")
card.push_to_hub("your-username/thesaurus-model")

Creating Hugging Face Spaces

Spaces allow you to create interactive demos for your models directly on the Hugging Face Hub:

Gradio Demo
import gradio as gr
from transformers import pipeline

# Load the model
model_id = "your-username/thesaurus-model"
pipe = pipeline("text-generation", model=model_id)

# Define the generation function
def generate_thesaurus(word, relation_type):
    prompt = f"Find {relation_type} for the word '{word}':"
    result = pipe(prompt, max_length=100, temperature=0.7)[0]["generated_text"]
    return result.split(prompt)[1].strip()

# Create the interface
demo = gr.Interface(
    fn=generate_thesaurus,
    inputs=[
        gr.Textbox(label="Word"),
        gr.Radio(["synonyms", "antonyms", "related terms"], label="Relation Type")
    ],
    outputs=gr.Textbox(label="Results"),
    title="Thesaurus AI",
    description="Generate synonyms, antonyms, and related terms for any word."
)

# Launch the demo
demo.launch()
Streamlit Demo
import streamlit as st
from transformers import pipeline

# Set page title
st.set_page_config(page_title="Thesaurus AI")

# Load the model
@st.cache_resource
def load_model():
    return pipeline("text-generation", model="your-username/thesaurus-model")

pipe = load_model()

# Create the UI
st.title("Thesaurus AI")
st.write("Generate synonyms, antonyms, and related terms for any word.")

word = st.text_input("Enter a word:")
relation_type = st.selectbox(
    "Select relation type:",
    ["synonyms", "antonyms", "related terms"]
)

if st.button("Generate"):
    if word:
        with st.spinner("Generating..."):
            prompt = f"Find {relation_type} for the word '{word}':"
            result = pipe(prompt, max_length=100, temperature=0.7)[0]["generated_text"]
            output = result.split(prompt)[1].strip()
            st.success(f"**{relation_type.title()} for '{word}':**")
            st.write(output)
    else:
        st.error("Please enter a word.")

Advanced Hugging Face Features

Model Versioning

Hugging Face Hub supports Git-based versioning for your models:

# Push a specific version/tag
model.push_to_hub("your-username/thesaurus-model", tags=["v1.0.0"])

# Create a model repository with specific branch
from huggingface_hub import create_repo, HfApi

create_repo("your-username/thesaurus-model", private=True)
api = HfApi()
api.upload_folder(
    folder_path="./thesaurus_model_final",
    repo_id="your-username/thesaurus-model",
    revision="dev"  # Push to a specific branch
)

Model Inference API

Hugging Face provides a hosted Inference API for your models:

# Using the Inference API
import requests

API_URL = "https://api-inference.huggingface.co/models/your-username/thesaurus-model"
headers = {"Authorization": f"Bearer {API_TOKEN}"}

def query(payload):
    response = requests.post(API_URL, headers=headers, json=payload)
    return response.json()

output = query({
    "inputs": "Find synonyms for the word 'happy':",
    "parameters": {
        "max_length": 100,
        "temperature": 0.7
    }
})
