Python Code Example

Here's how to use the pipeline API in your own code:

from transformers import pipeline

# Initialize the pipeline with your selected task and model
pipe = pipeline(
    "text-generation",
    model="gpt2",
    device=0  # Use GPU if available
)

# Run inference
result = pipe(
    "Once upon a time",
    max_length=50,
    temperature=0.7,
    top_p=0.9,
    num_return_sequences=1
)

print(result[0]['generated_text'])

For fine-tuned models, you can load them from the Hugging Face Hub or a local directory:

from transformers import pipeline

# Load a fine-tuned model from Hugging Face Hub
pipe = pipeline(
    "text-generation",
    model="your-username/your-fine-tuned-model"
)

# Or load from a local directory
pipe = pipeline(
    "text-generation",
    model="./path/to/your/fine-tuned-model"
)

result = pipe("Your prompt here", max_length=50)
print(result[0]['generated_text'])
