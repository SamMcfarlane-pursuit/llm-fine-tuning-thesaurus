LangGraph for LLM Fine-Tuning

Learn how to use LangGraph to build advanced applications with fine-tuned language models

Introduction to LangGraph

LangGraph is a library for building stateful, multi-actor applications with LLMs. It extends LangChain with a graph-based orchestration layer that allows you to build complex, multi-step workflows with fine-tuned language models.

Key features of LangGraph include:

  • Stateful Workflows: Build applications that maintain state across multiple interactions
  • Multi-Actor Systems: Create systems with multiple LLM agents that collaborate
  • Graph-Based Orchestration: Define complex workflows using a graph structure
  • Seamless Integration: Works with fine-tuned models from Hugging Face, OpenAI, and other providers

LangGraph orchestrates complex LLM workflows

What is LangGraph?

LangGraph is built on top of LangChain and provides a way to create stateful, multi-actor applications with LLMs. It's particularly useful for building complex applications that require multiple steps, memory, and reasoning.

Installation and Setup

To get started with LangGraph, you'll need to install the library and its dependencies:

# Install LangGraph and LangChain

Basic Concepts

Nodes and Edges

LangGraph uses a graph structure to define workflows. The key components are:

  • Nodes: Functions or components that perform specific tasks (e.g., generating text, making decisions)
  • Edges: Connections between nodes that define the flow of data and control
  • State: Information that persists across multiple steps in the workflow

Building a Simple Graph

Here's a basic example of creating a simple LangGraph workflow:

from langgraph.graph import StateGraph
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage

# Define the state
class GraphState(TypedDict):
    messages: List[Union[HumanMessage, AIMessage]]
    next_step: Optional[str]

# Create a model
model = ChatOpenAI(model="gpt-3.5-turbo")

# Define nodes
def generate_response(state: GraphState) -> GraphState:
    messages = state["messages"]
    response = model.invoke(messages)
    return {"messages": messages + [response]}

def decide_next_step(state: GraphState) -> GraphState:
    messages = state["messages"]
    response = model.invoke(
        messages + [HumanMessage(content="Based on our conversation, what should we do next? Answer with either 'continue' or 'end'")]
    )
    decision = response.content.strip().lower()
    return {"next_step": "continue" if "continue" in decision else "end"}

# Create the graph
graph = StateGraph(GraphState)

# Add nodes
graph.add_node("generate", generate_response)
graph.add_node("decide", decide_next_step)

# Add edges
graph.add_edge("generate", "decide")
graph.add_conditional_edges(
    "decide",
    lambda state: state["next_step"],
    {
        "continue": "generate",
        "end": END
    }
)

# Set the entry point
graph.set_entry_point("generate")

# Compile the graph
app = graph.compile()

Using Local Fine-Tuned Models with PEFT

from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel
from langchain_huggingface import HuggingFacePipeline
from langchain_core.prompts import PromptTemplate
from langgraph.graph import StateGraph
import torch

# Load a locally fine-tuned model with PEFT
base_model = AutoModelForCausalLM.from_pretrained(
    "distilgpt2",
    device_map="auto",
    torch_dtype=torch.float16
)
model = PeftModel.from_pretrained(base_model, "./thesaurus-model-lora")
tokenizer = AutoTokenizer.from_pretrained("distilgpt2")

# Create a LangChain pipeline
pipeline = HuggingFacePipeline.from_model_id(
    model_id=None,
    task="text-generation",
    model=model,
    tokenizer=tokenizer,
    max_new_tokens=100,
    temperature=0.7
)

# Create a prompt template
prompt_template = PromptTemplate.from_template(
    "Generate synonyms for the word '{word}':\n\n"
)

# Define a node that uses the fine-tuned model
def generate_synonyms(state):
    word = state["word"]
    prompt = prompt_template.format(word=word)
    response = pipeline.invoke(prompt)
    return {"word": word, "synonyms": response}

# Create the graph
graph = StateGraph()
graph.add_node("generate_synonyms", generate_synonyms)
# ... add more nodes and edges as needed

Advanced Patterns for LLM Fine-Tuning Applications

Multi-Model Workflows

You can create workflows that use multiple fine-tuned models for different tasks:

from langgraph.graph import StateGraph
from langchain_huggingface import HuggingFaceEndpoint

# Load multiple fine-tuned models
synonym_model = HuggingFaceEndpoint(
    repo_id="your-username/synonym-model",
    task="text-generation"
)

definition_model = HuggingFaceEndpoint(
    repo_id="your-username/definition-model",
    task="text-generation"
)

example_model = HuggingFaceEndpoint(
    repo_id="your-username/example-model",
    task="text-generation"
)

# Define nodes for each model
def generate_synonyms(state):
    word = state["word"]
    response = synonym_model.invoke(f"Generate synonyms for '{word}':")
    return {"synonyms": response}

def generate_definition(state):
    word = state["word"]
    response = definition_model.invoke(f"Define the term '{word}':")
    return {"definition": response}

def generate_examples(state):
    word = state["word"]
    response = example_model.invoke(f"Provide usage examples for '{word}':")
    return {"examples": response}

# Create the graph
graph = StateGraph()
graph.add_node("synonyms", generate_synonyms)
graph.add_node("definition", generate_definition)
graph.add_node("examples", generate_examples)
graph.add_node("combine", lambda state: {
    "word": state["word"],
    "thesaurus_entry": {
        "synonyms": state["synonyms"],
        "definition": state["definition"],
        "examples": state["examples"]
    }
})

# Add edges
graph.add_edge("synonyms", "definition")
graph.add_edge("definition", "examples")
graph.add_edge("examples", "combine")

Feedback Loops and Refinement

You can create workflows that refine outputs through feedback loops:

from langgraph.graph import StateGraph
from langchain_openai import ChatOpenAI

# Create models
generator = ChatOpenAI(model="gpt-3.5-turbo")
evaluator = ChatOpenAI(model="gpt-4")

# Define nodes
def generate_content(state):
    topic = state["topic"]
    response = generator.invoke(f"Write a paragraph about {topic}.")
    return {"draft": response.content}

def evaluate_content(state):
    draft = state["draft"]
    evaluation = evaluator.invoke(
        f"Evaluate this paragraph and suggest improvements:\n\n{draft}"
    )
    quality_score = 0
    if "good" in evaluation.content.lower():
        quality_score = 8
    elif "excellent" in evaluation.content.lower():
        quality_score = 10
    else:
        quality_score = 5

    return {
        "evaluation": evaluation.content,
        "quality_score": quality_score
    }

def refine_content(state):
    draft = state["draft"]
    evaluation = state["evaluation"]

    response = generator.invoke(
        f"Refine this paragraph based on the feedback:\n\nParagraph: {draft}\n\nFeedback: {evaluation}"
    )

    return {"draft": response.content}

def decide_next_step(state):
    score = state["quality_score"]
    if score >= 8:
        return {"next_step": "complete"}
    else:
        return {"next_step": "refine"}

# Create the graph
graph = StateGraph()
graph.add_node("generate", generate_content)
graph.add_node("evaluate", evaluate_content)
graph.add_node("refine", refine_content)
graph.add_node("decide", decide_next_step)

# Add edges
graph.add_edge("generate", "evaluate")
graph.add_edge("evaluate", "decide")
graph.add_conditional_edges(
    "decide",
    lambda state: state["next_step"],
    {
        "refine": "refine",
        "complete": END
    }
)
graph.add_edge("refine", "evaluate")

Real-World Applications

Thesaurus Application with Fine-Tuned Models

Here's a complete example of building a thesaurus application using LangGraph and fine-tuned models:

from langgraph.graph import StateGraph
from langchain_huggingface import HuggingFacePipeline
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel
import torch
from typing import TypedDict, List, Dict, Optional
from fastapi import FastAPI
from pydantic import BaseModel

# Define the state
class ThesaurusState(TypedDict):
    word: str
    synonyms: Optional[List[str]]
    antonyms: Optional[List[str]]
    related_terms: Optional[List[str]]
    definition: Optional[str]
    examples: Optional[List[str]]
    complete: bool

# Load fine-tuned model
base_model = AutoModelForCausalLM.from_pretrained(
    "distilgpt2",
    device_map="auto",
    torch_dtype=torch.float16
)
model = PeftModel.from_pretrained(base_model, "./thesaurus-model-lora")
tokenizer = AutoTokenizer.from_pretrained("distilgpt2")

# Create pipeline
pipeline = HuggingFacePipeline.from_model_id(
    model_id=None,
    task="text-generation",
    model=model,
    tokenizer=tokenizer,
    max_new_tokens=100,
    temperature=0.7
)

# Define nodes
def generate_synonyms(state: ThesaurusState) -> Dict:
    word = state["word"]
    prompt = f"Generate synonyms for the word '{word}':"
    response = pipeline.invoke(prompt)

    # Extract synonyms from response
    synonyms_text = response.split("Synonyms:")[1].split("\n")[0] if "Synonyms:" in response else response
    synonyms = [s.strip() for s in synonyms_text.split(",")]

    return {"synonyms": synonyms}

def generate_antonyms(state: ThesaurusState) -> Dict:
    word = state["word"]
    prompt = f"Generate antonyms for the word '{word}':"
    response = pipeline.invoke(prompt)

    # Extract antonyms from response
    antonyms_text = response.split("Antonyms:")[1].split("\n")[0] if "Antonyms:" in response else response
    antonyms = [a.strip() for a in antonyms_text.split(",")]

    return {"antonyms": antonyms}

def generate_related(state: ThesaurusState) -> Dict:
    word = state["word"]
    prompt = f"Generate related terms for the word '{word}':"
    response = pipeline.invoke(prompt)

    # Extract related terms from response
    related_text = response.split("Related Terms:")[1].split("\n")[0] if "Related Terms:" in response else response
    related_terms = [r.strip() for r in related_text.split(",")]

    return {"related_terms": related_terms}

def generate_definition(state: ThesaurusState) -> Dict:
    word = state["word"]
    prompt = f"Define the word '{word}':"
    response = pipeline.invoke(prompt)

    # Extract definition from response
    definition = response.split("Definition:")[1].split("\n")[0] if "Definition:" in response else response

    return {"definition": definition.strip()}

def generate_examples(state: ThesaurusState) -> Dict:
    word = state["word"]
    prompt = f"Provide usage examples for the word '{word}':"
    response = pipeline.invoke(prompt)

    # Extract examples from response
    examples_text = response.split("Examples:")[1] if "Examples:" in response else response
    examples = [e.strip() for e in examples_text.split("\n") if e.strip()]

    return {"examples": examples}

def finalize_entry(state: ThesaurusState) -> Dict:
    return {"complete": True}

# Create the graph
graph = StateGraph(ThesaurusState)

# Add nodes
graph.add_node("synonyms", generate_synonyms)
graph.add_node("antonyms", generate_antonyms)
graph.add_node("related", generate_related)
graph.add_node("definition", generate_definition)
graph.add_node("examples", generate_examples)
graph.add_node("finalize", finalize_entry)

# Add edges
graph.add_edge("synonyms", "antonyms")
graph.add_edge("antonyms", "related")
graph.add_edge("related", "definition")
graph.add_edge("definition", "examples")
graph.add_edge("examples", "finalize")

# Set entry point
graph.set_entry_point("synonyms")

# Compile the graph
thesaurus_app = graph.compile()

# Create FastAPI app
app = FastAPI(title="Thesaurus API")

class WordRequest(BaseModel):
    word: str

@app.post("/thesaurus")
async def get_thesaurus_entry(request: WordRequest):
    # Initialize state
    initial_state = {"word": request.word, "complete": False}

    # Run the graph
    result = thesaurus_app.invoke(initial_state)

    # Return the result
    return {
        "word": request.word,
        "synonyms": result["synonyms"],
        "antonyms": result["antonyms"],
        "related_terms": result["related_terms"],
        "definition": result["definition"],
        "examples": result["examples"]
    }

Best Practices

Performance Optimization

  • Batch Processing: Process multiple inputs in batches when possible
  • Caching: Use caching to avoid redundant model calls
  • Quantization: Use quantized models for faster inference
  • Parallel Execution: Use parallel execution for independent nodes

Error Handling

  • Graceful Fallbacks: Implement fallback mechanisms for when models fail
  • Retry Logic: Add retry logic for transient errors
  • Validation: Validate inputs and outputs at each step
  • Monitoring: Add monitoring to track performance and errors
Common Pitfalls
  • Memory Leaks: Be careful with large state objects that can cause memory issues
  • Infinite Loops: Ensure your conditional edges have proper termination conditions
  • Error Propagation: Handle errors at each node to prevent cascading failures
  • State Mutation: Avoid mutating state directly; always return new state objects
