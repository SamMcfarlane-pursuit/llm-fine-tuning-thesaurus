Exercise 1: Understanding Pre-trained Models

What are Pre-trained Models?

Pre-trained models are large neural networks that have been trained on vast amounts of text data to learn language patterns. They serve as the foundation for fine-tuning.

Common Pre-trained Models:

  • GPT (Generative Pre-trained Transformer): Autoregressive language models that generate text by predicting the next token.
  • BERT (Bidirectional Encoder Representations from Transformers): Bidirectional models that understand context from both directions.
  • T5 (Text-to-Text Transfer Transformer): Encoder-decoder models that frame all NLP tasks as text-to-text problems.

Hands-on Task:

In this exercise, we'll explore the GPT-2 model that we'll use for our thesaurus application:

from transformers import AutoModelForCausalLM, AutoTokenizer

# Load the model and tokenizer
model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# Print model information
print(f"Model: {model_name}")
print(f"Parameter count: {sum(p.numel() for p in model.parameters()):,}")
print(f"Vocabulary size: {len(tokenizer)}")

# Try a simple generation
prompt = "A synonym for happy is"
inputs = tokenizer(prompt, return_tensors="pt")
outputs = model.generate(inputs.input_ids, max_length=20, num_return_sequences=1)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))

Exercise 2: Data Preparation for Fine-Tuning

Preparing Data for Fine-Tuning

Fine-tuning requires high-quality, task-specific data. For our thesaurus application, we need data that includes words and their relationships.

Key Steps in Data Preparation:

  1. Collecting relevant data (synonyms, antonyms, etc.)
  2. Formatting data in a suitable structure
  3. Tokenizing and encoding the data
  4. Creating training and validation splits

Hands-on Task:

In this exercise, we'll prepare thesaurus data using WordNet:

import nltk
from nltk.corpus import wordnet as wn
import json

# Download WordNet
nltk.download('wordnet')
nltk.download('omw-1.4')

# Generate thesaurus data for a few words
words = ["happy", "good", "fast", "big", "small"]
thesaurus_data = []

for word in words:
    entry = {"word": word, "synonyms": [], "antonyms": []}

    # Get synsets for the word
    synsets = wn.synsets(word)

    for synset in synsets:
        # Get synonyms
        for lemma in synset.lemmas():
            if lemma.name() != word and '_' not in lemma.name():
                entry["synonyms"].append(lemma.name())

            # Get antonyms
            for antonym in lemma.antonyms():
                if '_' not in antonym.name():
                    entry["antonyms"].append(antonym.name())

    # Remove duplicates
    entry["synonyms"] = list(set(entry["synonyms"]))
    entry["antonyms"] = list(set(entry["antonyms"]))

    thesaurus_data.append(entry)

# Print the data
for entry in thesaurus_data:
    print(f"Word: {entry['word']}")
    print(f"Synonyms: {', '.join(entry['synonyms'])}")
    print(f"Antonyms: {', '.join(entry['antonyms'])}")
    print()

Exercise 3: Fine-Tuning with LoRA

What is LoRA?

LoRA (Low-Rank Adaptation) is a parameter-efficient fine-tuning technique that adds trainable low-rank matrices to the model's weights while keeping the original weights frozen.

Benefits of LoRA:

  • Significantly fewer trainable parameters
  • Lower memory requirements
  • Faster training
  • Prevents catastrophic forgetting

Hands-on Task:

In this exercise, we'll apply LoRA to fine-tune GPT-2 for our thesaurus application:

from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments, Trainer
from peft import LoraConfig, get_peft_model, TaskType
from datasets import Dataset

# Prepare training data in the right format
def format_examples(thesaurus_data):
    examples = []
    for entry in thesaurus_data:
        word = entry["word"]
        if entry["synonyms"]:
            synonyms_str = ", ".join(entry["synonyms"])
            examples.append(f"### Instruction: List synonyms for the word '{word}'.\n\n### Response: Synonyms for '{word}': {synonyms_str}")
    return examples

# Create a dataset
texts = format_examples(thesaurus_data)
dataset = Dataset.from_dict({"text": texts})
dataset = dataset.train_test_split(test_size=0.1)

# Load the model and tokenizer
model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token
model = AutoModelForCausalLM.from_pretrained(model_name)

# Configure LoRA
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=8,                     # Rank of the update matrices
    lora_alpha=32,           # Parameter for scaling
    lora_dropout=0.1,        # Dropout probability for LoRA layers
    bias="none",             # Don't add bias parameters
    target_modules=["c_attn", "c_proj"]  # Attention modules to apply LoRA to
)

# Apply LoRA to the model
peft_model = get_peft_model(model, lora_config)

# Print trainable parameters
trainable_params = sum(p.numel() for p in peft_model.parameters() if p.requires_grad)
total_params = sum(p.numel() for p in peft_model.parameters())
print(f"Trainable parameters: {trainable_params:,} ({trainable_params/total_params:.2%} of total)")

# Define training arguments
training_args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=2,
    warmup_steps=100,
    weight_decay=0.01,
    logging_dir="./logs",
    logging_steps=10,
    save_strategy="epoch",
    learning_rate=1e-4,
    fp16=True,  # Use mixed precision training
    report_to="none"
)

# Tokenize the dataset
def tokenize_function(examples):
    return tokenizer(examples["text"], padding="max_length", truncation=True, max_length=128)

tokenized_dataset = dataset.map(tokenize_function, batched=True)

# Create Trainer and train the model
trainer = Trainer(
    model=peft_model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    eval_dataset=tokenized_dataset["test"],
)

# Train the model
trainer.train()

# Save the LoRA adapter only (much smaller than full model)
peft_model.save_pretrained("./thesaurus-model-lora")
tokenizer.save_pretrained("./thesaurus-model-lora")

print("Fine-tuning complete! The model has been saved to ./thesaurus-model-lora")

Exercise 4: Evaluating Your Fine-Tuned Model

Why Evaluate Your Model?

Evaluation helps you understand how well your fine-tuned model performs on the specific task it was trained for. For a thesaurus model, we want to evaluate how well it can generate synonyms and related words.

Key Evaluation Metrics:

  • Accuracy: How many of the generated synonyms are correct
  • Recall: How many of the known synonyms the model can generate
  • Relevance: How semantically related the generated words are to the input
  • Diversity: The variety of synonyms generated

Hands-on Task:

In this exercise, we'll evaluate our fine-tuned thesaurus model:

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel
import nltk
from nltk.corpus import wordnet as wn

# Download WordNet if not already downloaded
nltk.download('wordnet')
nltk.download('omw-1.4')

# Load the base model
base_model = AutoModelForCausalLM.from_pretrained("gpt2")

# Load the fine-tuned model with LoRA adapter
model = PeftModel.from_pretrained(base_model, "./thesaurus-model-lora")
tokenizer = AutoTokenizer.from_pretrained("./thesaurus-model-lora")

# Set up evaluation
test_words = ["intelligent", "beautiful", "interesting", "difficult", "important"]
results = []

# Function to get WordNet synonyms for comparison
def get_wordnet_synonyms(word):
    synonyms = set()
    for synset in wn.synsets(word):
        for lemma in synset.lemmas():
            if lemma.name() != word and "_" not in lemma.name():
                synonyms.add(lemma.name())
    return list(synonyms)

# Function to generate synonyms using our model
def generate_synonyms(word, max_length=50):
    prompt = f"### Instruction: List synonyms for the word '{word}'.\n\n### Response:"
    inputs = tokenizer(prompt, return_tensors="pt")

    with torch.no_grad():
        outputs = model.generate(
            inputs.input_ids,
            max_length=max_length,
            num_return_sequences=1,
            temperature=0.7,
            top_p=0.9,
            do_sample=True
        )

    generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
    # Extract just the synonyms part
    if "Synonyms for" in generated_text and ":" in generated_text:
        synonyms_text = generated_text.split(":", 1)[1].strip()
        # Split by commas and clean up
        generated_synonyms = [s.strip().lower() for s in synonyms_text.split(",")]
        return generated_synonyms
    return []

# Evaluate each test word
for word in test_words:
    # Get ground truth synonyms from WordNet
    wordnet_synonyms = get_wordnet_synonyms(word)

    # Generate synonyms with our model
    generated_synonyms = generate_synonyms(word)

    # Calculate metrics
    correct_synonyms = [s for s in generated_synonyms if s in wordnet_synonyms]
    accuracy = len(correct_synonyms) / len(generated_synonyms) if generated_synonyms else 0
    recall = len(correct_synonyms) / len(wordnet_synonyms) if wordnet_synonyms else 0

    # Store results
    results.append({
        "word": word,
        "wordnet_synonyms": wordnet_synonyms,
        "generated_synonyms": generated_synonyms,
        "accuracy": accuracy,
        "recall": recall
    })

# Print evaluation results
print("\nEvaluation Results:")
print("-" * 50)
for result in results:
    print(f"Word: {result['word']}")
    print(f"WordNet Synonyms: {', '.join(result['wordnet_synonyms'][:5])}{'...' if len(result['wordnet_synonyms']) > 5 else ''}")
    print(f"Generated Synonyms: {', '.join(result['generated_synonyms'])}")
    print(f"Accuracy: {result['accuracy']:.2f}")
    print(f"Recall: {result['recall']:.2f}")
    print("-" * 50)

# Calculate overall metrics
avg_accuracy = sum(r['accuracy'] for r in results) / len(results)
avg_recall = sum(r['recall'] for r in results) / len(results)
print(f"\nOverall Accuracy: {avg_accuracy:.2f}")
print(f"Overall Recall: {avg_recall:.2f}")

Exercise 5: Building a Thesaurus Application

From Model to Application

Now that we have a fine-tuned model, let's build a simple thesaurus application that allows users to look up synonyms for words.

Key Components:

  • Model loading and inference
  • User interface for input and output
  • Response formatting and presentation
  • Error handling and edge cases

Hands-on Task:

In this exercise, we'll create a simple thesaurus application using our fine-tuned model:

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel
import gradio as gr

# Load the model
def load_model():
    # Load the base model
    base_model = AutoModelForCausalLM.from_pretrained("gpt2")

    # Load the fine-tuned model with LoRA adapter
    model = PeftModel.from_pretrained(base_model, "./thesaurus-model-lora")
    tokenizer = AutoTokenizer.from_pretrained("./thesaurus-model-lora")

    return model, tokenizer

# Generate synonyms for a given word
def generate_synonyms(word, model, tokenizer, max_length=50):
    prompt = f"### Instruction: List synonyms for the word '{word}'.\n\n### Response:"
    inputs = tokenizer(prompt, return_tensors="pt")

    with torch.no_grad():
        outputs = model.generate(
            inputs.input_ids,
            max_length=max_length,
            num_return_sequences=1,
            temperature=0.7,
            top_p=0.9,
            do_sample=True
        )

    generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
    return generated_text

# Format the response for better presentation
def format_response(response):
    if "Synonyms for" in response and ":" in response:
        # Extract the word and synonyms
        word_part = response.split("Synonyms for")[1].split(":")[0].strip()
        synonyms_part = response.split(":")[1].strip()

        # Format the synonyms as a list
        synonyms = [s.strip() for s in synonyms_part.split(",")]
        formatted_synonyms = "
    " + "".join([f"
  • {s}
    • " for s in synonyms]) + "
"

        return f"
Synonyms for {word_part}:
{formatted_synonyms}"
    else:
        return response

# Create the Gradio interface
def create_interface():
    model, tokenizer = load_model()

    def process_input(word):
        if not word.strip():
            return "Please enter a word."

        try:
            response = generate_synonyms(word.strip().lower(), model, tokenizer)
            return format_response(response)
        except Exception as e:
            return f"Error: {str(e)}"

    interface = gr.Interface(
        fn=process_input,
        inputs=gr.Textbox(placeholder="Enter a word...", label="Word"),
        outputs=gr.HTML(label="Synonyms"),
        title="LLM-Powered Thesaurus",
        description="Enter a word to find its synonyms using our fine-tuned language model.",
        examples=["happy", "intelligent", "beautiful", "fast", "important"]
    )

    return interface

# Launch the application
if __name__ == "__main__":
    interface = create_interface()
    interface.launch()
    print("Thesaurus application is running!")

          "quantized_model.pth")

Exercise 7: Advanced Fine-Tuning with QLoRA

What is QLoRA?

QLoRA (Quantized Low-Rank Adaptation) is an advanced fine-tuning technique that combines quantization with LoRA to enable fine-tuning of large language models with even less memory.

Key Benefits of QLoRA:

  • Memory Efficiency: Fine-tune large models (up to 65B parameters) on a single consumer GPU
  • Preserved Performance: Maintains model quality comparable to full fine-tuning
  • Reduced Precision: Uses 4-bit quantization for the base model weights
  • Backpropagation Compatible: Allows gradient flow through quantized weights

How QLoRA Works:

  1. Quantize the pre-trained model weights to 4-bit precision
  2. Keep a small set of trainable LoRA parameters in higher precision (16-bit)
  3. Use a technique called Double Quantization to further reduce memory usage
  4. Implement Paged Optimizers to handle memory spikes during training

Hands-on Task:

In this exercise, we'll fine-tune a larger model using QLoRA:

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments, Trainer
from datasets import Dataset
from peft import prepare_model_for_kbit_training, LoraConfig, get_peft_model
from bitsandbytes.nn import Linear4bit

# Prepare training data (same as before)
def format_examples(thesaurus_data):
    examples = []
    for entry in thesaurus_data:
        word = entry["word"]
        if entry["synonyms"]:
            synonyms_str = ", ".join(entry["synonyms"])
            examples.append(f"### Instruction: List synonyms for the word '{word}'.\n\n### Response: Synonyms for '{word}': {synonyms_str}")
    return examples

# Create a dataset
texts = format_examples(thesaurus_data)
dataset = Dataset.from_dict({"text": texts})
dataset = dataset.train_test_split(test_size=0.1)

# Load a larger model in 4-bit precision
model_name = "facebook/opt-1.3b"  # Using a larger model than before

# Load in 4-bit precision with specific quantization settings
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    load_in_4bit=True,
    device_map="auto",
    quantization_config={
        "bnb_4bit_compute_dtype": torch.float16,
        "bnb_4bit_use_double_quant": True,
        "bnb_4bit_quant_type": "nf4"  # NormalFloat 4-bit
    }
)

# Load tokenizer
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token

# Prepare model for k-bit training
model = prepare_model_for_kbit_training(model)

# Configure LoRA
lora_config = LoraConfig(
    r=16,                     # Higher rank for more capacity
    lora_alpha=32,
    target_modules=["q_proj", "v_proj", "k_proj", "o_proj", "gate_proj", "up_proj", "down_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

# Apply LoRA to the model
model = get_peft_model(model, lora_config)

# Print trainable parameters
trainable_params = sum(p.numel() for p in model.parameters() if p.requires_grad)
total_params = sum(p.numel() for p in model.parameters())
print(f"Trainable parameters: {trainable_params:,} ({trainable_params/total_params:.2%} of total)")

# Define training arguments with gradient checkpointing and mixed precision
training_args = TrainingArguments(
    output_dir="./results-qlora",
    num_train_epochs=3,
    per_device_train_batch_size=2,  # Smaller batch size for larger model
    gradient_accumulation_steps=4,  # Increase gradient accumulation
    warmup_steps=100,
    weight_decay=0.01,
    logging_dir="./logs-qlora",
    logging_steps=10,
    save_strategy="epoch",
    learning_rate=2e-4,
    fp16=True,  # Use mixed precision training
    gradient_checkpointing=True,  # Enable gradient checkpointing
    report_to="none"
)

# Tokenize the dataset
def tokenize_function(examples):
    return tokenizer(examples["text"], padding="max_length", truncation=True, max_length=128)

tokenized_dataset = dataset.map(tokenize_function, batched=True)

# Create Trainer and train the model
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    eval_dataset=tokenized_dataset["test"],
)

# Train the model
trainer.train()

# Save the LoRA adapter only
model.save_pretrained("./thesaurus-qlora-adapter")
tokenizer.save_pretrained("./thesaurus-qlora-adapter")

print("QLoRA fine-tuning complete! The model has been saved to ./thesaurus-qlora-adapter")

QLoRA 1.3B parameters ~4-5 GB Consumer (RTX 3060)

Exercise 8: Other Advanced Fine-Tuning Techniques

Prefix Tuning

Prefix Tuning prepends trainable continuous vectors ("virtual tokens") to the input sequence, keeping the pre-trained model frozen.

Key Features:
  • Only trains a small set of continuous prefix vectors
  • Extremely parameter-efficient (< 1% of parameters)
  • Particularly effective for NLG tasks
from peft import PrefixTuningConfig, get_peft_model

# Configure Prefix Tuning
prefix_config = PrefixTuningConfig(
    task_type="CAUSAL_LM",
    num_virtual_tokens=20,  # Number of virtual tokens
    prefix_projection=True,  # Use projection layer
    encoder_hidden_size=512  # Size of prefix encoder
)

# Apply Prefix Tuning to the model
prefix_model = get_peft_model(model, prefix_config)

# Print trainable parameters
trainable_params = sum(p.numel() for p in prefix_model.parameters()
                      if p.requires_grad)
print(f"Trainable parameters: {trainable_params:,}")

Prompt Tuning

Prompt Tuning trains continuous embeddings that are prepended to the input embeddings, while keeping the model frozen.

Key Features:
  • Simpler than Prefix Tuning (no projection layers)
  • Extremely parameter-efficient
  • Scales well with model size
from peft import PromptTuningConfig, get_peft_model, TaskType

# Configure Prompt Tuning
prompt_config = PromptTuningConfig(
    task_type=TaskType.CAUSAL_LM,
    num_virtual_tokens=10,  # Number of virtual tokens
    tokenizer_name_or_path=model_name,
    prompt_tuning_init="RANDOM"  # Initialize randomly
)

# Apply Prompt Tuning to the model
prompt_model = get_peft_model(model, prompt_config)

# Print trainable parameters
trainable_params = sum(p.numel() for p in prompt_model.parameters()
                      if p.requires_grad)
print(f"Trainable parameters: {trainable_params:,}")

Adapter Layers

Adapter Layers insert small trainable modules between layers of the frozen pre-trained model.

Key Features:
  • Bottleneck architecture reduces parameter count
  • Can be placed at various positions in the network
  • Modular and composable for multi-task learning
from peft import AdapterConfig, get_peft_model

# Configure Adapter
adapter_config = AdapterConfig(
    r=16,  # Bottleneck dimension
    lora_alpha=32,
    lora_dropout=0.05,
    task_type="CAUSAL_LM",
    bias="none"
)

# Apply Adapter to the model
adapter_model = get_peft_model(model, adapter_config)

# Print trainable parameters
trainable_params = sum(p.numel() for p in adapter_model.parameters()
                      if p.requires_grad)
print(f"Trainable parameters: {trainable_params:,}")

P-Tuning v2

P-Tuning v2 is an improved version of prompt tuning that adds deep prompt embeddings at each layer of the model.

Key Features:
  • Adds prompts to multiple layers, not just the input
  • More expressive than standard prompt tuning
  • Particularly effective for NLU tasks
from peft import PromptEncoderConfig, get_peft_model, TaskType

# Configure P-Tuning v2
ptuning_config = PromptEncoderConfig(
    task_type=TaskType.CAUSAL_LM,
    num_virtual_tokens=20,  # Number of virtual tokens
    encoder_hidden_size=128,  # Hidden size of prompt encoder
    encoder_num_layers=2,  # Number of layers in prompt encoder
