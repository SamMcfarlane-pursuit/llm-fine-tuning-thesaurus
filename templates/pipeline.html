What is the Pipeline API?

The Hugging Face pipeline API provides a simple way to use pre-trained models for various NLP tasks without having to handle the underlying model architecture details.

Pipeline Code Example

Here's how to use the pipeline API in your own Python code:

from transformers import pipeline

# Initialize a pipeline for sentiment analysis
classifier = pipeline('sentiment-analysis')

# Run inference
result = classifier('I really enjoyed this movie. The acting was great!')

print(result)
# Output: [{'label': 'POSITIVE', 'score': 0.9998}]

You can use different tasks by changing the pipeline type:

# Named Entity Recognition
ner = pipeline('ner')
ner_results = ner('Apple is looking at buying U.K. startup for $1 billion')

# Question Answering
qa = pipeline('question-answering')
qa_result = qa(
    question='What is the capital of France?',
    context='Paris is the capital and most populous city of France.'
)

# Text Generation
generator = pipeline('text-generation')
generator_result = generator('Once upon a time', max_length=50)

# Summarization
summarizer = pipeline('summarization')
summarizer_result = summarizer('''
    The Amazon rainforest, also known as Amazonia, is a moist broadleaf
    tropical rainforest in the Amazon biome that covers most of the Amazon
    basin of South America. This basin encompasses 7,000,000 km².
''', max_length=100, min_length=30)

You can also specify a particular model to use:

# Use a specific model for sentiment analysis
specific_classifier = pipeline(
    'sentiment-analysis',
    model='distilbert-base-uncased-finetuned-sst-2-english'
)

# Use a specific model for text generation
specific_generator = pipeline(
    'text-generation',
    model='gpt2-medium'
)

Available Tasks

  • Text Classification

    Classify text into predefined categories, such as sentiment analysis (positive/negative).

  • Named Entity Recognition

    Identify entities like people, organizations, locations, etc. in text.

  • Question Answering

    Extract answers from a context given a question.

  • Summarization

    Generate concise summaries of longer texts.

  • Text Generation

    Generate text based on a prompt.

  • Translation

    Translate text from one language to another.

  • Conversational

    Chat with a model in a conversational manner.
