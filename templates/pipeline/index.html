Hugging Face Pipeline

Learn about and experiment with the Hugging Face pipeline API

What is the Pipeline API?

The Hugging Face pipeline() API is a high-level interface that simplifies using pre-trained models for inference. It abstracts away the complexity of loading models, preprocessing inputs, and postprocessing outputs, allowing you to focus on your application rather than implementation details.

Easy to Use

Just a few lines of code to get state-of-the-art NLP results

Pre-trained Models

Access to thousands of pre-trained models for various tasks

Customizable

Use your own fine-tuned models with the same interface

Hardware Optimized

Automatically uses GPU when available for faster inference

Available Tasks

The pipeline API supports a wide range of NLP tasks. Here are some of the most common ones:

Sentiment Analysis

Determine if text expresses positive, negative, or neutral sentiment

from transformers import pipeline
classifier = pipeline('sentiment-analysis')
classifier('I love this product!')

Text Generation

Generate text based on a prompt

from transformers import pipeline
generator = pipeline('text-generation')
generator('Hugging Face is')

Question Answering

Answer questions based on context

from transformers import pipeline
qa = pipeline('question-answering')
qa(question='What is Hugging Face?', 
   context='Hugging Face is a company that provides NLP tools.')

Summarization

Generate concise summaries of longer texts

from transformers import pipeline
summarizer = pipeline('summarization')
summarizer('Hugging Face is a company that...')
