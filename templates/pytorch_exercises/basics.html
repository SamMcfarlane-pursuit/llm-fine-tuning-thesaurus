PyTorch Basics

Learn the fundamentals of PyTorch by working with tensors, autograd, and basic operations.

Learning Objectives

By the end of this exercise, you will be able to:

  • Create and manipulate tensors in PyTorch
  • Understand automatic differentiation with autograd
  • Perform basic mathematical operations on tensors
  • Compute gradients for optimization
  • Build a simple computational graph

Prerequisites

Before starting this exercise, you should have:

  • Basic knowledge of Python programming
  • Familiarity with NumPy (helpful but not required)
  • PyTorch installed on your machine

Installation

If you haven't installed PyTorch yet, you can do so using pip:

Exercise 1: Creating and Manipulating Tensors

In this exercise, you'll learn how to create tensors of different shapes and types, and how to perform basic operations on them.

Step 1: Import PyTorch

Python 
import torch
import numpy as np

# Check PyTorch version
print("PyTorch version:", torch.__version__)

Step 2: Create Tensors

Let's create tensors of different dimensions:

Python 
# Scalar (0D tensor)
scalar = torch.tensor(7)
print("Scalar:", scalar)
print("Shape:", scalar.shape)
print("Datatype:", scalar.dtype)

# Vector (1D tensor)
vector = torch.tensor([1, 2, 3, 4, 5])
print("\nVector:", vector)
print("Shape:", vector.shape)

# Matrix (2D tensor)
matrix = torch.tensor([[1, 2, 3], [4, 5, 6]])
print("\nMatrix:", matrix)
print("Shape:", matrix.shape)

# 3D tensor
tensor_3d = torch.tensor([[[1, 2], [3, 4]], [[5, 6], [7, 8]]])
print("\n3D Tensor:", tensor_3d)
print("Shape:", tensor_3d.shape)

Step 3: Create Tensors from NumPy Arrays

Python 
# Create a NumPy array
np_array = np.array([[1, 2, 3], [4, 5, 6]])

# Convert to PyTorch tensor
tensor_from_np = torch.from_numpy(np_array)
print("Tensor from NumPy:", tensor_from_np)

# Convert back to NumPy
back_to_np = tensor_from_np.numpy()
print("Back to NumPy:", back_to_np)

Step 4: Tensor Operations

Python 
# Create two tensors
a = torch.tensor([[1, 2], [3, 4]])
b = torch.tensor([[5, 6], [7, 8]])

# Addition
c = a + b  # or torch.add(a, b)
print("Addition:", c)

# Subtraction
d = a - b  # or torch.sub(a, b)
print("Subtraction:", d)

# Element-wise multiplication
e = a * b  # or torch.mul(a, b)
print("Element-wise multiplication:", e)

# Matrix multiplication
f = torch.matmul(a, b)
print("Matrix multiplication:", f)

# Division
g = a / b  # or torch.div(a, b)
print("Division:", g)

Exercise 2: Automatic Differentiation with Autograd

In this exercise, you'll learn about PyTorch's autograd system for automatic differentiation.

Step 1: Tensors with Gradients

Python 
# Create tensors with requires_grad=True
x = torch.tensor(3.0, requires_grad=True)
y = torch.tensor(2.0, requires_grad=True)

# Perform operations
z = x**2 + y**3

# Compute gradients
z.backward()

# Access gradients
print(f"dz/dx: {x.grad}")  # Should be 2x = 6
print(f"dz/dy: {y.grad}")  # Should be 3y^2 = 12

Step 2: Gradient Accumulation and Zeroing

Python 
# Create a tensor with requires_grad=True
x = torch.tensor(2.0, requires_grad=True)

# First computation
y1 = x**2
y1.backward()
print(f"First gradient: {x.grad}")  # Should be 2x = 4

# Gradients accumulate by default
y2 = x**3
y2.backward()
print(f"Accumulated gradient: {x.grad}")  # Should be 4 + 3x^2 = 4 + 12 = 16

# Zero the gradients
x.grad.zero_()
print(f"After zeroing: {x.grad}")

# New computation
y3 = x**4
y3.backward()
print(f"New gradient: {x.grad}")  # Should be 4x^3 = 32

Step 3: Gradient Descent Example

Python 
# Define a simple function to minimize: f(x) = x^2
def f(x):
    return x**2

# Initialize the tensor
x = torch.tensor(5.0, requires_grad=True)
learning_rate = 0.1
steps = 20

print(f"Initial x: {x.item()}, f(x): {f(x).item()}")

for i in range(steps):
    # Forward pass: compute the function value
    y = f(x)
    
    # Backward pass: compute the gradient
    y.backward()
    
    # Update x using gradient descent
    with torch.no_grad():  # Temporarily disable gradient tracking
        x -= learning_rate * x.grad
    
    # Reset gradients for the next iteration
    x.grad.zero_()
    
    print(f"Step {i+1}: x = {x.item():.4f}, f(x) = {f(x).item():.4f}")

Exercise 3: Building a Simple Model

In this exercise, you'll build a simple linear regression model using PyTorch's low-level API.

Step 1: Generate Synthetic Data

Python 
# Generate synthetic data
np.random.seed(42)
x_data = np.random.rand(100, 1)
y_data = 2 * x_data + 1 + 0.1 * np.random.randn(100, 1)  # y = 2x + 1 + noise

# Convert to tensors
x = torch.from_numpy(x_data).float()
y = torch.from_numpy(y_data).float()

Step 2: Define Model Parameters

Python 
# Initialize model parameters
W = torch.randn(1, 1, requires_grad=True)
b = torch.zeros(1, requires_grad=True)

Step 3: Define Model and Loss Function

Python 
# Define the model
def linear_model(x):
    return torch.matmul(x, W) + b

# Define the loss function (mean squared error)
def loss_fn(y_pred, y_true):
    return torch.mean((y_pred - y_true)**2)

Step 4: Training Loop

Python 
# Define optimizer
learning_rate = 0.1
epochs = 100

for epoch in range(epochs):
    # Forward pass
    y_pred = linear_model(x)
    loss = loss_fn(y_pred, y)
    
    # Backward pass
    loss.backward()
    
    # Update parameters
    with torch.no_grad():
        W -= learning_rate * W.grad
        b -= learning_rate * b.grad
    
    # Reset gradients
    W.grad.zero_()
    b.grad.zero_()
    
    if epoch % 10 == 0:
        print(f"Epoch {epoch}: Loss = {loss.item():.4f}, W = {W.item():.4f}, b = {b.item():.4f}")

Step 5: Visualize Results

Python 
import matplotlib.pyplot as plt

# Plot the data and the fitted line
plt.scatter(x_data, y_data, label='Data')
plt.plot(x_data, W.detach().numpy() * x_data + b.detach().numpy(), 'r', label='Fitted line')
plt.legend()
plt.xlabel('x')
plt.ylabel('y')
plt.title('Linear Regression with PyTorch')
plt.show()

print(f"True parameters: W = 2, b = 1")
print(f"Learned parameters: W = {W.item():.4f}, b = {b.item():.4f}")
