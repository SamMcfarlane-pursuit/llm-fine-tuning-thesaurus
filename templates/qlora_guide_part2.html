Implementing QLoRA with Hugging Face

Required Libraries

To implement QLoRA, you'll need the following libraries:

pip install transformers>=4.30.0 peft>=0.4.0 bitsandbytes>=0.39.0 accelerate>=0.20.0 datasets trl
Library Versions

QLoRA requires specific versions of these libraries to work properly. Make sure you're using compatible versions.

Basic QLoRA Implementation

Here's a step-by-step implementation of QLoRA fine-tuning:

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig

# Define quantization config
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.float16,
    bnb_4bit_use_double_quant=True
)

# Load model in 4-bit precision
model_id = "meta-llama/Llama-2-7b-hf"  # or any other model
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    quantization_config=bnb_config,
    device_map="auto"
)

# Load tokenizer
tokenizer = AutoTokenizer.from_pretrained(model_id)
tokenizer.pad_token = tokenizer.eos_token
Important Note

For some models like Llama-2, you'll need to have accepted the model license on Hugging Face and have a valid access token.

from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training, TaskType

# Prepare model for k-bit training
model = prepare_model_for_kbit_training(model)

# Define LoRA configuration
lora_config = LoraConfig(
    r=16,                       # Rank
    lora_alpha=32,              # Alpha parameter for LoRA scaling
    target_modules=[
        "q_proj",
        "k_proj",
        "v_proj",
        "o_proj",
        "gate_proj",
        "up_proj",
        "down_proj"
    ],
    lora_dropout=0.05,          # Dropout probability for LoRA layers
    bias="none",                # Add bias to LoRA layers
    task_type=TaskType.CAUSAL_LM # Task type
)

# Apply LoRA to the model
model = get_peft_model(model, lora_config)

# Print trainable parameters
def print_trainable_parameters(model):
    trainable_params = 0
    all_params = 0
    for _, param in model.named_parameters():
        all_params += param.numel()
        if param.requires_grad:
            trainable_params += param.numel()
    print(f"Trainable params: {trainable_params} ({100 * trainable_params / all_params:.2f}% of all params)")

print_trainable_parameters(model)
Target Modules

The target_modules parameter specifies which layers to apply LoRA to. These module names vary by model architecture, so you may need to adjust them based on your specific model.

from datasets import load_dataset

# Load dataset (example using a dataset from Hugging Face)
dataset = load_dataset("databricks/databricks-dolly-15k")

# Function to format prompts
def format_prompt(sample):
    """Format the prompt based on the template."""
    instruction = sample["instruction"]
    context = sample["context"] if sample["context"] else ""
    response = sample["response"]
    
    if context:
        formatted_prompt = f"""### Instruction:
{instruction}

### Context:
{context}

### Response:
{response}"""
    else:
        formatted_prompt = f"""### Instruction:
{instruction}

### Response:
{response}"""
    
    return formatted_prompt

# Process the dataset
def process_dataset(dataset):
    """Process the dataset for training."""
    processed_data = []
    
    for sample in dataset:
        formatted_text = format_prompt(sample)
        processed_data.append({"text": formatted_text})
    
    return processed_data

# Process the dataset
train_data = process_dataset(dataset["train"])
eval_data = process_dataset(dataset["test"]) if "test" in dataset else None

# Convert to Dataset object
from datasets import Dataset
train_dataset = Dataset.from_list(train_data)
eval_dataset = Dataset.from_list(eval_data) if eval_data else None

from transformers import TrainingArguments

# Define training arguments
training_args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=2,
    gradient_checkpointing=True,
    optim="paged_adamw_32bit",
    learning_rate=2e-4,
    weight_decay=0.001,
    fp16=True,
    logging_steps=10,
    evaluation_strategy="steps" if eval_dataset else "no",
    eval_steps=50 if eval_dataset else None,
    save_strategy="steps",
    save_steps=50,
    save_total_limit=3,
    load_best_model_at_end=True if eval_dataset else False,
    report_to="tensorboard",
    remove_unused_columns=False,
)
Key Parameters
  • gradient_checkpointing: Saves memory by recomputing gradients during backpropagation
  • optim="paged_adamw_32bit": Uses memory-efficient optimizer
  • gradient_accumulation_steps: Accumulates gradients over multiple batches to simulate larger batch sizes

from transformers import DataCollatorForLanguageModeling

# Define data collator
data_collator = DataCollatorForLanguageModeling(
    tokenizer=tokenizer,
    mlm=False  # Not using masked language modeling
)

# Tokenization function
def tokenize_function(examples):
    return tokenizer(
        examples["text"],
        truncation=True,
        max_length=512,
        padding="max_length",
    )

# Tokenize datasets
tokenized_train_dataset = train_dataset.map(
    tokenize_function,
    batched=True,
    remove_columns=["text"] if "text" in train_dataset.column_names else None
)

tokenized_eval_dataset = None
if eval_dataset:
    tokenized_eval_dataset = eval_dataset.map(
        tokenize_function,
        batched=True,
        remove_columns=["text"] if "text" in eval_dataset.column_names else None
    )

from transformers import Trainer

# Initialize trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_train_dataset,
    eval_dataset=tokenized_eval_dataset,
    data_collator=data_collator,
)

# Train the model
trainer.train()

# Save the trained model
model.save_pretrained("./qlora_model")
tokenizer.save_pretrained("./qlora_model")

from peft import AutoPeftModelForCausalLM

# Load the trained model
adapter_model = AutoPeftModelForCausalLM.from_pretrained("./qlora_model")

# Merge adapter weights with base model
merged_model = adapter_model.merge_and_unload()

# Save the merged model
merged_model.save_pretrained("./merged_model")
tokenizer.save_pretrained("./merged_model")
Memory Requirements

Merging the adapter with the base model requires significantly more memory than training with QLoRA. Make sure you have enough GPU or CPU memory for this step.

Best Practices for QLoRA Fine-Tuning

Hyperparameter Selection

Parameter Recommended Value Notes
LoRA rank (r) 8-64 Higher values = more capacity but more memory
LoRA alpha 16-64 Usually 2x the rank value
Learning rate 1e-4 to 3e-4 Smaller models may use higher rates
Batch size 1-8 Use gradient accumulation for larger effective batches
Training epochs 2-5 Depends on dataset size

Memory Optimization Tips

  • Use gradient checkpointing: Reduces memory usage by recomputing gradients during backpropagation.
  • Enable flash attention: If available for your model, it significantly reduces memory usage.
  • Optimize sequence length: Only use as much context as needed for your task.
  • Use paged optimizers: They manage memory more efficiently for optimizer states.
  • Limit target modules: Apply LoRA to fewer layers if memory is still an issue.

Common Issues and Solutions

Problem: CUDA out of memory errors during training.

Solutions:

  • Reduce batch size
  • Enable gradient checkpointing
  • Reduce sequence length
  • Apply LoRA to fewer layers
  • Use a smaller base model
  • Increase gradient accumulation steps

Problem: Model doesn't learn effectively or produces poor results.

Solutions:

  • Increase LoRA rank (r)
  • Apply LoRA to more layers
  • Check data quality and formatting
  • Adjust learning rate
  • Train for more epochs
  • Use a different base model

Problem: Training is taking too long.

Solutions:

  • Use a smaller base model
  • Reduce the dataset size
  • Decrease sequence length
  • Apply LoRA to fewer layers
  • Use mixed precision training (fp16)
  • Use a more powerful GPU

Problem: Errors related to library versions or compatibility.

Solutions:

  • Ensure compatible versions of all libraries
  • Use a virtual environment
  • Check for CUDA compatibility
  • Update to the latest versions of libraries
  • Check GitHub issues for known problems
