TensorFlow Basics

Learn the fundamentals of TensorFlow by working with tensors, variables, and basic operations.

Learning Objectives

By the end of this exercise, you will be able to:

  • Create and manipulate tensors in TensorFlow
  • Understand the difference between tensors and variables
  • Perform basic mathematical operations on tensors
  • Use automatic differentiation to compute gradients
  • Build a simple computational graph

Prerequisites

Before starting this exercise, you should have:

  • Basic knowledge of Python programming
  • Familiarity with NumPy (helpful but not required)
  • TensorFlow 2.x installed on your machine

Installation

If you haven't installed TensorFlow yet, you can do so using pip:

Terminal 
pip install tensorflow

Exercise 1: Creating and Manipulating Tensors

In this exercise, you'll learn how to create tensors of different shapes and types, and how to perform basic operations on them.

Step 1: Import TensorFlow

Python 
import tensorflow as tf
import numpy as np

# Check TensorFlow version
print("TensorFlow version:", tf.__version__)

Step 2: Create Tensors

Let's create tensors of different dimensions:

Python 
# Scalar (0D tensor)
scalar = tf.constant(7)
print("Scalar:", scalar)
print("Shape:", scalar.shape)
print("Datatype:", scalar.dtype)

# Vector (1D tensor)
vector = tf.constant([1, 2, 3, 4, 5])
print("\nVector:", vector)
print("Shape:", vector.shape)

# Matrix (2D tensor)
matrix = tf.constant([[1, 2, 3], [4, 5, 6]])
print("\nMatrix:", matrix)
print("Shape:", matrix.shape)

# 3D tensor
tensor_3d = tf.constant([[[1, 2], [3, 4]], [[5, 6], [7, 8]]])
print("\n3D Tensor:", tensor_3d)
print("Shape:", tensor_3d.shape)

Step 3: Create Tensors from NumPy Arrays

Python 
# Create a NumPy array
np_array = np.array([[1, 2, 3], [4, 5, 6]])

# Convert to TensorFlow tensor
tensor_from_np = tf.constant(np_array)
print("Tensor from NumPy:", tensor_from_np)

# Convert back to NumPy
back_to_np = tensor_from_np.numpy()
print("Back to NumPy:", back_to_np)

Step 4: Tensor Operations

Python 
# Create two tensors
a = tf.constant([[1, 2], [3, 4]])
b = tf.constant([[5, 6], [7, 8]])

# Addition
c = a + b  # or tf.add(a, b)
print("Addition:", c)

# Subtraction
d = a - b  # or tf.subtract(a, b)
print("Subtraction:", d)

# Element-wise multiplication
e = a * b  # or tf.multiply(a, b)
print("Element-wise multiplication:", e)

# Matrix multiplication
f = tf.matmul(a, b)
print("Matrix multiplication:", f)

# Division
g = a / b  # or tf.divide(a, b)
print("Division:", g)

Exercise 2: Variables and Gradients

In this exercise, you'll learn about TensorFlow variables and how to compute gradients using automatic differentiation.

Step 1: Create Variables

Python 
# Create a variable
w = tf.Variable([[1.0, 2.0], [3.0, 4.0]])
print("Variable:", w)

# Update the variable
w.assign(w + 1)
print("Updated variable:", w)

# Create a variable with a specific dtype
v = tf.Variable(tf.random.normal([2, 3], mean=0, stddev=1), dtype=tf.float32)
print("Random variable:", v)

Step 2: Automatic Differentiation with GradientTape

Python 
# Define a function
def f(x):
    return tf.square(x) + 2*x - 5

# Compute the gradient at x=3
x = tf.Variable(3.0)
with tf.GradientTape() as tape:
    y = f(x)
    
# dy/dx at x=3
dy_dx = tape.gradient(y, x)
print(f"f(x) = x² + 2x - 5")
print(f"f'(x) at x=3 is {dy_dx.numpy()}")  # Should be 2x + 2 = 8 at x=3

Step 3: Gradient Descent Example

Python 
# Define a simple function to minimize: f(x) = x^2
def f(x):
    return tf.square(x)

# Initialize the variable
x = tf.Variable(5.0)
learning_rate = 0.1
steps = 20

print(f"Initial x: {x.numpy()}, f(x): {f(x).numpy()}")

for i in range(steps):
    with tf.GradientTape() as tape:
        y = f(x)
    
    # Compute the gradient
    dy_dx = tape.gradient(y, x)
    
    # Update x using gradient descent
    x.assign_sub(learning_rate * dy_dx)
    
    print(f"Step {i+1}: x = {x.numpy():.4f}, f(x) = {f(x).numpy():.4f}")

Exercise 3: Building a Simple Model

In this exercise, you'll build a simple linear regression model using TensorFlow's low-level API.

Step 1: Generate Synthetic Data

Python 
# Generate synthetic data
np.random.seed(42)
x_data = np.random.rand(100, 1)
y_data = 2 * x_data + 1 + 0.1 * np.random.randn(100, 1)  # y = 2x + 1 + noise

# Convert to tensors
x = tf.constant(x_data, dtype=tf.float32)
y = tf.constant(y_data, dtype=tf.float32)

Step 2: Define Model Parameters

Python 
# Initialize model parameters
W = tf.Variable(tf.random.normal([1, 1], mean=0, stddev=0.1))
b = tf.Variable(tf.zeros([1]))

Step 3: Define Model and Loss Function

Python 
# Define the model
def linear_model(x):
    return tf.matmul(x, W) + b

# Define the loss function (mean squared error)
def loss_fn(y_pred, y_true):
    return tf.reduce_mean(tf.square(y_pred - y_true))

Step 4: Training Loop

Python 
# Define optimizer
optimizer = tf.optimizers.SGD(learning_rate=0.1)

# Training loop
epochs = 100
for epoch in range(epochs):
    with tf.GradientTape() as tape:
        y_pred = linear_model(x)
        loss = loss_fn(y_pred, y)
    
    # Compute gradients
    gradients = tape.gradient(loss, [W, b])
    
    # Update parameters
    optimizer.apply_gradients(zip(gradients, [W, b]))
    
    if epoch % 10 == 0:
        print(f"Epoch {epoch}: Loss = {loss.numpy():.4f}, W = {W.numpy()[0][0]:.4f}, b = {b.numpy()[0]:.4f}")

Step 5: Visualize Results

Python 
import matplotlib.pyplot as plt

# Plot the data and the fitted line
plt.scatter(x_data, y_data, label='Data')
plt.plot(x_data, W.numpy() * x_data + b.numpy(), 'r', label='Fitted line')
plt.legend()
plt.xlabel('x')
plt.ylabel('y')
plt.title('Linear Regression with TensorFlow')
plt.show()

print(f"True parameters: W = 2, b = 1")
print(f"Learned parameters: W = {W.numpy()[0][0]:.4f}, b = {b.numpy()[0]:.4f}")
