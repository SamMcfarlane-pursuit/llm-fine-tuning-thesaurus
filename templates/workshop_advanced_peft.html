Introduction to Advanced PEFT Methods

1

Parameter-Efficient Fine-Tuning (PEFT) encompasses a variety of techniques beyond LoRA that enable efficient adaptation of large language models. In this module, we'll explore the landscape of PEFT methods and understand their relative strengths and applications.

Key PEFT Methods

  • Prefix Tuning: Prepends trainable continuous vectors to the input of each transformer layer
  • Prompt Tuning: Adds trainable soft prompt embeddings to the input sequence
  • P-Tuning v2: Combines aspects of prefix tuning and prompt tuning for improved performance
  • Adapter Layers: Inserts small trainable modules between layers of the pre-trained model
  • IA³: Infused Adapter by Inhibiting and Amplifying Inner Activations

Exercise 1.1: Comparing PEFT Methods

In this exercise, we'll compare different PEFT methods in terms of parameter efficiency and performance:

import numpy as np
import matplotlib.pyplot as plt

# PEFT methods and their characteristics
methods = [
    "Full Fine-tuning",
    "LoRA",
    "Prefix Tuning",
    "Prompt Tuning",
    "P-Tuning v2",
    "Adapter"
]

# Parameter efficiency (% of trainable parameters compared to full fine-tuning)
param_efficiency = [100, 0.5, 0.1, 0.01, 0.2, 0.3]

# Relative performance (example values, 100% = full fine-tuning performance)
performance = [100, 97, 95, 90, 96, 94]

# Create a comparison plot
fig, ax = plt.subplots(figsize=(12, 6))

x = np.arange(len(methods))
width = 0.35

ax.bar(x - width/2, param_efficiency, width, label='Parameter Efficiency (% of full model)')
ax.bar(x + width/2, performance, width, label='Relative Performance (%)')

ax.set_xticks(x)
ax.set_xticklabels(methods)
ax.legend()

plt.title('Comparison of PEFT Methods')
plt.xlabel('Method')
plt.ylabel('Percentage')
plt.ylim(0, 110)

for i, v in enumerate(param_efficiency):
    ax.text(i - width/2, v + 3, f"{v}%", ha='center')

for i, v in enumerate(performance):
    ax.text(i + width/2, v + 3, f"{v}%", ha='center')

plt.tight_layout()
plt.show()

Prefix Tuning Implementation

2

Prefix Tuning is a technique that prepends trainable continuous vectors (prefixes) to the keys and values in each transformer layer. This approach is particularly effective for sequence generation tasks.

Key Concepts

  • Prefix Tokens: Trainable vectors added to each transformer layer
  • Reparameterization Trick: Using a smaller MLP to generate the prefix parameters
  • Layer-wise Prefixes: Different prefixes for different layers

Exercise 2.1: Implementing Prefix Tuning with PEFT

In this exercise, we'll implement Prefix Tuning using the PEFT library:

from transformers import AutoModelForSeq2SeqLM, AutoTokenizer
from peft import get_peft_model, PrefixTuningConfig, TaskType

# 1. Load pre-trained model and tokenizer
model_name = "t5-small"  # Using a small model for demonstration
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

# 2. Configure Prefix Tuning
peft_config = PrefixTuningConfig(
    task_type=TaskType.SEQ_2_SEQ_LM,
    num_virtual_tokens=20,  # Number of virtual tokens to add
    prefix_projection=True,  # Use the reparameterization trick
    encoder_hidden_size=512,  # Hidden size for the prefix MLP
)

# 3. Apply Prefix Tuning to the model
model = get_peft_model(model, peft_config)

# Print trainable parameters
model.print_trainable_parameters()

# Example inference with the model
input_text = "translate English to French: Hello, how are you?"
input_ids = tokenizer(input_text, return_tensors="pt").input_ids

# Generate text
output = model.generate(
    input_ids=input_ids,
    max_length=50,
    num_return_sequences=1,
)

# Decode and print the generated text
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Generated text: {generated_text}")

P-Tuning v2 Implementation

3

P-Tuning v2 is an improved version of prompt tuning that adds deep prompt embeddings to each layer of the transformer. It's particularly effective for natural language understanding tasks.

Implementation Steps

  1. Configure P-Tuning v2 parameters
  2. Apply P-Tuning to the model
  3. Fine-tune on a downstream task
  4. Evaluate the results

Exercise 3.1: Implementing P-Tuning v2 with PEFT

In this exercise, we'll implement P-Tuning v2 for a classification task:

from transformers import AutoModelForSequenceClassification, AutoTokenizer
from peft import get_peft_model, PromptTuningConfig, TaskType, PromptTuningInit

# 1. Load pre-trained model and tokenizer
model_name = "roberta-base"  # Using RoBERTa for classification
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)

# 2. Configure P-Tuning v2
peft_config = PromptTuningConfig(
    task_type=TaskType.SEQ_CLS,
    prompt_tuning_init=PromptTuningInit.TEXT,  # Initialize with text
    num_virtual_tokens=20,  # Number of virtual tokens
    tokenizer_name_or_path=model_name,
    prompt_tuning_init_text="Classify the following text as positive or negative:",
)

# 3. Apply P-Tuning to the model
model = get_peft_model(model, peft_config)

# Print trainable parameters
model.print_trainable_parameters()

# Example inference with the model
input_text = "I really enjoyed this movie, the acting was superb!"
inputs = tokenizer(input_text, return_tensors="pt")

# Get classification logits
outputs = model(**inputs)
logits = outputs.logits

# Get predicted class (0 = negative, 1 = positive)
predicted_class = logits.argmax(-1).item()
print(f"Input: {input_text}")
print(f"Predicted class: {'Positive' if predicted_class == 1 else 'Negative'}")

Adapter Layers Implementation

4

Adapter Layers are small trainable modules inserted between layers of the pre-trained model. They're particularly effective for multi-task learning and transfer learning scenarios.

Key Concepts

  • Bottleneck Architecture: Down-projection followed by up-projection
  • Residual Connections: Preserving the original signal through skip connections
  • Adapter Fusion: Combining multiple task-specific adapters

Exercise 4.1: Implementing Adapter Layers

In this exercise, we'll implement Adapter Layers for a language model:

from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import get_peft_model, AdaptionPromptConfig, TaskType

# 1. Load pre-trained model and tokenizer
model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# 2. Configure Adapter
peft_config = AdaptionPromptConfig(
    task_type=TaskType.CAUSAL_LM,
    adapter_layers=30,  # Number of adapter layers to add
    adapter_len=32,     # Length of adapter tokens
)

# 3. Apply Adapter to the model
model = get_peft_model(model, peft_config)

# Print trainable parameters
model.print_trainable_parameters()

# Example inference with the model
input_text = "Adapter layers in language models are useful because"
input_ids = tokenizer(input_text, return_tensors="pt").input_ids

# Generate text
output = model.generate(
    input_ids=input_ids,
    max_length=50,
    num_return_sequences=1,
    temperature=0.7,
)

# Decode and print the generated text
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Generated text: {generated_text}")
