Introduction to LoRA

1

Low-Rank Adaptation (LoRA) is a technique for efficiently fine-tuning large language models by freezing the pre-trained model weights and injecting trainable rank decomposition matrices into each layer of the Transformer architecture.

Key Concepts

  • Parameter-Efficient Fine-Tuning (PEFT): Approaches that adapt pre-trained language models to specific tasks with significantly fewer trainable parameters
  • Low-Rank Decomposition: Approximating a large matrix using the product of two smaller matrices
  • Rank (r): A hyperparameter that determines the size of the low-rank matrices and the capacity of the adaptation
  • Alpha (α): A scaling factor that controls the magnitude of the LoRA update

Exercise 1.1: Understanding LoRA Mathematics

In this exercise, we'll explore the mathematical foundations of LoRA and how it reduces the number of trainable parameters.

import numpy as np

# Original weight matrix (pretrained, frozen)
W = np.random.randn(768, 768)  # Example size for a transformer layer

# LoRA parameters
r = 8  # Rank
alpha = 16  # Scaling factor

# LoRA matrices (trainable)
A = np.random.randn(768, r)  # Down-projection
B = np.zeros((r, 768))  # Up-projection (initialized to zero)

# LoRA update calculation
delta_W = (alpha / r) * (A @ B)

# Effective weight matrix during inference
W_effective = W + delta_W

# Calculate parameter counts
params_original = W.size
params_lora = A.size + B.size
reduction_factor = params_original / params_lora

print(f"Original parameters: {params_original:,}")
print(f"LoRA parameters: {params_lora:,}")
print(f"Parameter reduction: {reduction_factor:.2f}x")

Try different values of rank (r) and observe how it affects the parameter count and reduction factor.

Exercise 3.1: Implementing LoRA with PEFT

In this exercise, we'll implement LoRA fine-tuning on a small language model:

from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import get_peft_model, LoraConfig, TaskType

# 1. Load pre-trained model and tokenizer
model_name = "gpt2"  # Using a small model for demonstration
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# 2. Configure LoRA
peft_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=8,  # Rank
    lora_alpha=16,  # Alpha parameter
    lora_dropout=0.1,  # Dropout probability for LoRA layers
    # Target the attention modules
    target_modules=["c_attn", "c_proj"],
    bias="none",  # Don't train bias parameters
)

# 3. Apply LoRA to the model
model = get_peft_model(model, peft_config)

# Print trainable parameters
model.print_trainable_parameters()

# Example inference with the model
input_text = "Fine-tuning large language models with LoRA"
input_ids = tokenizer(input_text, return_tensors="pt").input_ids

# Generate text
output = model.generate(
    input_ids=input_ids,
    max_length=50,
    num_return_sequences=1,
    temperature=0.7,
)

# Decode and print the generated text
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Generated text: {generated_text}")
