Available Workshops

Workshop 1: Full Fine-Tuning

4 hours

Master the fundamentals of full fine-tuning for language models, including dataset preparation, training configuration, and evaluation.

What You'll Learn:
  • Preparing and formatting datasets for fine-tuning
  • Configuring training hyperparameters
  • Implementing full fine-tuning with Hugging Face
  • Evaluating model performance
Start Workshop

Workshop 2: LoRA Fine-Tuning

5 hours

Learn how to implement Low-Rank Adaptation (LoRA) for efficient fine-tuning of large language models with limited computational resources.

What You'll Learn:
  • Understanding LoRA architecture and mathematics
  • Implementing LoRA with the PEFT library
  • Optimizing rank and alpha parameters
  • Merging LoRA adapters with base models
Start Workshop

Workshop 3: QLoRA Deep Dive

6 hours

Master Quantized Low-Rank Adaptation (QLoRA) for fine-tuning extremely large models on consumer hardware through advanced memory optimization techniques.

What You'll Learn:
  • 4-bit NF4 quantization implementation
  • Double quantization techniques
  • Paged optimizers and gradient checkpointing
  • Fine-tuning 13B+ parameter models on consumer GPUs
Start Workshop

Workshop: Memory Efficiency in LLM Fine-Tuning

3 hours

Learn essential memory efficiency techniques for fine-tuning large language models with limited hardware resources, focusing on the most important concepts for learning and retention.

What You'll Learn:
  • Quantization techniques (4-bit, 8-bit, NF4)
  • Gradient checkpointing for activation memory reduction
  • Parameter-efficient fine-tuning methods (LoRA, QLoRA)
  • Memory-efficient optimizers and attention mechanisms
Start Workshop

Workshop 4: Advanced PEFT Techniques

8 hours

Explore advanced Parameter-Efficient Fine-Tuning (PEFT) methods beyond LoRA, including Prefix Tuning, P-Tuning, Adapter Layers, and more.

What You'll Learn:
  • Implementing Prefix Tuning for sequence generation
  • P-Tuning v2 for natural language understanding
  • Adapter Layers for multi-task learning
  • Comparing PEFT methods and choosing the right approach
Start Workshop

Workshop 5: Instruction Fine-Tuning

5 hours

Learn how to fine-tune models to follow specific instructions and generate high-quality responses for conversational AI applications.

What You'll Learn:
  • Preparing instruction-response datasets
  • Implementing RLHF (Reinforcement Learning from Human Feedback)
  • Fine-tuning with instruction templates
  • Evaluating instruction-following capabilities
Start Workshop

Workshop 6: Deployment & Optimization

7 hours

Master the techniques for deploying fine-tuned models in production environments, including quantization, distillation, and optimization for inference.

What You'll Learn:
  • ONNX conversion and optimization
  • Knowledge distillation for smaller models
  • Quantization for inference
  • Deploying with Docker, FastAPI, and cloud services
Start Workshop

Workshop Prerequisites

Knowledge Prerequisites

  • Basic understanding of deep learning concepts
  • Familiarity with Python programming
  • Experience with PyTorch or TensorFlow
  • Understanding of transformer architecture basics

Technical Requirements

  • GPU with at least 8GB VRAM (16GB+ recommended)
  • Multi-core CPU with 16GB+ RAM
  • 50GB+ free disk space
  • Alternative: Google Colab Pro or similar cloud GPU service
Can't meet the hardware requirements?

All workshops include Google Colab notebooks that can be run on free or paid Colab instances. The QLoRA workshop specifically focuses on techniques to fine-tune large models with limited resources.
